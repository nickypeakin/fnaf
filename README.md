# Blockcraft

A blocky survival-and-building game for the browser, based on the Caves & Cliffs era of a well-known
block game, that you can play with friends. Everything runs from static files: open
`index.html` (or the GitHub Pages link) and play. All textures, models and sounds are made in code, so
the art is original.

**Play:** https://nickypeakin.github.io/fnaf/

## What's in it

- **Caves & Cliffs world generation:** tall mountains, cliffs and peaks, the world from y −64 up to
  191, deepslate below y 0, cheese, spaghetti and noodle caves, underground water and lava lakes, ores at their
  Caves & Cliffs heights (copper, iron, coal, gold, lapis, redstone, diamond and emerald, plus
  deepslate variants), **lush caves** (moss, azalea, glowing cave vines, dripleaf, spore blossoms),
  **dripstone caves**, **amethyst geodes**, tuff, calcite and glow lichen.
- **Biomes:** plains, forests, birch and dark forest, taiga, jungle, savanna, desert, snowy plains,
  meadow, cherry grove, grove, snowy slopes, jagged and stony peaks, beaches, rivers and oceans.
- **534 crafting recipes and 80 smelting recipes:** all the wood types (oak, spruce, birch, jungle,
  acacia, dark oak, cherry), every stone, deepslate and tuff family (slabs, stairs, walls, polished,
  bricks, tiles, chiseled), copper blocks at every stage of weathering (cut, chiseled, grates, bulbs,
  doors, trapdoors), tools, armor, 16 colours of wool, carpet, glass, terracotta, concrete, beds and
  candles, food, and utility blocks. The **recipe book** (green book button) lists every recipe and fills
  the grid for you.
- **Survival:** health, hunger, saturation, drowning, fall damage, lava, freezing in powder snow, armor,
  tool durability, experience, furnaces, blast furnaces and smokers, chests and barrels, beds that skip the
  night and set your spawn point, farming, bone meal, saplings that grow into trees, flowing water and
  lava (water + lava makes cobblestone, stone or obsidian), falling sand and gravel, TNT, and buckets.
- **Mobs:** zombies and skeletons (they burn in daylight), creepers, spiders, pigs, cows (milk them),
  sheep (shear and dye them), chickens (they lay eggs), and from Caves & Cliffs: **goats**, **axolotls** and
  **glow squid**. Feed two animals to breed them.
- **Creative mode** with a searchable item palette and flying.
- **Multiplayer:** host a world and share the 5-letter room code; friends join from *Multiplayer → Join Room*.
  Everyone builds in the same world, sees each other, fights the same mobs and shares chests and furnaces.
- Day/night cycle, clouds, sunrise colours, smooth lighting, chat and commands, and saving in your browser.

Some newer items are in too (tuff bricks, copper grates and bulbs, the mace and wind charges in creative).

## Controls

| Action | Keys |
| --- | --- |
| Move / jump / sneak / sprint | W A S D · Space · Shift · Ctrl or double-tap W |
| Break / attack | Hold left mouse |
| Place / use | Right mouse |
| Pick block | Middle mouse |
| Inventory | E |
| Hotbar | 1–9 or mouse wheel |
| Drop item / swap hands | Q · F |
| Chat and commands | T or / |
| Debug screen / hide HUD | F3 · F1 |
| Fly (creative) | Double-tap Space |

Phones and tablets get on-screen controls.

Commands: `/gamemode survival|creative|spectator`, `/time set day|night`, `/tp x y z`, `/give item [count]`,
`/summon mob`, `/seed`, `/spawn`, `/setspawn`, `/difficulty`, `/kill`, `/help`.

## Multiplayer

1. One person creates or opens a world with **Host** (or presses **Open to Friends** in the pause menu).
2. They tell friends the **room code** shown in the top-right corner.
3. Friends choose **Multiplayer**, type their name and the code, and press **Join Room**.

The host's computer runs the world (mobs, items, furnaces), so the world stays open while the host is
playing. Connections are peer-to-peer (WebRTC via PeerJS's free signalling server). Some strict networks
or privacy blockers stop peer-to-peer connections; if joining fails, try another network.

## Needs WebGL 2

The game draws the world with WebGL 2. If a privacy or anti-fingerprinting extension blocks WebGL,
allow it for this site. The game shows a message if it can't start.

## Not included (yet)

The Nether and the End, redstone circuits, enchanting and brewing, villages and structures, weather,
and boats/minecarts as vehicles. These items exist but don't do much yet.

## Development

No build step. To serve locally:

```bash
python3 -m http.server 8000
```

Textures, item icons and `js/atlas.js` are generated by a Node script after you add blocks or items:

```bash
node tools/build-textures.js
```

Code layout:

- `js/blocks.js` — every block and item; `js/recipes.js` — crafting and smelting
- `js/worldgen.js` — terrain, caves, ores, biomes and trees
- `js/world-worker.js` — runs in a Web Worker: generates chunks, computes light, builds meshes
- `js/renderer.js` — WebGL 2 drawing; `js/world.js` — chunk streaming, raycasts, collisions
- `js/player.js` — movement physics; `js/game.js` — gameplay; `js/entities.js` — mobs and items
- `js/ui.js` — HUD and inventory screens; `js/net.js` — multiplayer; `js/save.js` — saving; `js/main.js` — menus
